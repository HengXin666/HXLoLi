## 先记住一件事: 收益 = 你扛得住的风险 × 你熬得住的时间

整个系列都在讲这一条. 股票长期年化大约 10%, 这个数是真的, 但它只发给两种人: 中途跌一半还不卖的人, 和能等十年以上的人

<Flow caption="一笔钱从口袋走到股票里, 中间有三道关" steps={[
{ name: "应急金: 3 到 6 个月生活费, 随取随用", tone: "ok" }, { name: "还掉年化 13% 以上的债: 花呗分期, 白条, 网贷", tone: "bad" }, { name: "确认有医保, 补便宜的意外险", tone: "ok" }, { name: "剩下几年内用不到的钱, 才拿去投资", tone: "good" }, ]} />

顺序反过来会怎样: 钱全在股票里, 手机摔了, 家里有事, 你只能在跌了 30% 的那天卖掉. 不是股票让你亏的, 是<Red>你被逼着在最差的时候离场</Red>

## 应急金先放好, 它不是用来赚钱的

场景: 你攒了 5000 块, 觉得放余额宝一年才几十块利息, 太亏了, 想全投股市

朴素做法是把所有钱都拿去 "钱生钱". 坏在 2026 年无风险的钱几乎不生息, 你会觉得留现金很傻, 于是一分不留

先看现实, 这几个数都是 2026 年 11 月的

<Stats items={[
{ value: "0.796%", label: "余额宝 7 日年化 (2026-11-26)", source: "天天基金 000198" }, { value: "约 1.05%", label: "全市场货币基金平均 7 日年化", source: "上海证券报, 截至 2026-11-23" }, { value: "0.95%", label: "工行 1 年定期挂牌利率", source: "工行官网, 2025-05-20 起执行" }, { value: "1.59%", label: "10 年期国债收益率 (2026-11-26)", source: "新华财经债市日报" }, ]} />

1 万块放余额宝一年, 大约拿到 80 块. 应急金的价值不是利息, 是你需要钱的时候<Gold>不用卖掉任何会跌的东西</Gold>

怎么修: 留 3 到 6 个月生活费在活期或货币基金 (买短期存单和国债的基金, 余额宝就是一只)

学生家里能兜底可以少留, 但至少够一次手机坏了, 生病, 临时回家. 这一步来自《漫步华尔街》第 12 章 "不要在急需用钱时发现囊中空空"

## 还掉一笔 18% 的债, 等于稳赚 18%

场景: 你花呗分期买了台电脑, 同时又想每月定投 500

朴素做法是 "分期慢慢还, 闲钱拿去投资, 两不耽误". 坏在分期和网贷的真实利率远比页面上写的高, 而世界上没有任何稳健投资能长期稳定跑赢它

算一算才知道多贵, 下面是按公式自己算的

<Compare caption="页面上写的 vs 实际年化" left={{
title: "宣传说法", items: ["日息万五, 听着很少", "月手续费 0.6%, 一年才 7.2%"], }} right={{title: "折成年化", items: ["日息万五 = 单利 18.25%, 复利约 20%", "按月等额还, 实际年化约 13.0%, 是名义的 1.8 倍"], }} />

为什么 0.6% 的月费会变 13%: 你每个月都在还本金, 欠的钱越来越少, 手续费却一直按最初的全额收

监管也知道这个坑. 央行 2021 年第 3 号公告要求所有贷款<Gold>必须明示年化利率</Gold>, 只写日息和月费率的宣传要警惕

最高法把民间借贷的司法保护上限定在 1 年期 LPR 的 4 倍, 按现在 3.0% 的 LPR (贷款市场报价利率, 银行贷款利率的参考线) 算是 12%

怎么修: 先还年化最高的那笔. 校园贷, "先享后付" 一类的东西, 能不碰就不碰

## 股票是公司的一小块所有权, 不是一张彩票

场景: 你在 App 里看到一只股票三天涨了 30%, 问 "它为什么涨", 评论区说 "主力在拉"

朴素理解是股票就是一串会跳的数字, 买低卖高就行. 坏在这种理解里没有任何东西能告诉你它值多少钱, 你只能猜别人怎么想

换个角度: 买一股, 你就成了这家公司的小股东, 拿到它未来利润的一小份分成权. 长期来看, 股票的回报只来自三块

<Layers caption="越往上越靠不住, 时间越长下面两层越重要" items={[
{ name: "估值变化", desc: "市场愿意给的倍数变了, 也就是情绪. 短期涨跌主要是它", weight: 1, tone: "bad" }, { name: "盈利增长", desc: "公司赚的钱变多了", weight: 2, tone: "good" }, { name: "分红", desc: "公司把利润直接发给你", weight: 2, tone: "good" }, ]} />

先锋集团创始人博格在《共同基金常识》里说过: 时间从 1 年拉到 25 年, 投机的影响就消退了, 回报开始跟着股息率和盈利增长走. 所以<Red>持有越短, 越是在赌情绪</Red>

## 三个数看懂一只股票贵不贵

场景: 朋友说 "这只股才 5 块钱, 好便宜"

朴素做法是看股价高低. 坏在股价本身毫无意义, 一家公司可以发 1 亿股也可以发 100 亿股, 股价差一百倍, 公司还是那家公司

真正比贵不贵的是下面三个比值

- **市盈率 PE = 股价 ÷ 每股盈利**. 直观意思: 按现在的利润, 多少年能回本. PE 越高, 市场对未来增长期待越高
- **市净率 PB = 股价 ÷ 每股净资产**. 为每 1 元家底付了多少钱. 适合银行, 地产这类重资产行业
- **股息率 = 每股年分红 ÷ 股价**. 不卖股票每年能拿回多少现金

它们各有骗人的时候: 周期股在利润最高时 PE 最低, 反而最危险; 股价暴跌时股息率会虚高, 分红也可能被砍

拿沪深 300 (A 股市值最大的 300 家公司组成的指数) 举例, 中证指数公司 2026-10-30 的指数单张写着 PE 12.61, PB 1.3, 股息率 2.73%

股息率比 10 年国债高约 1.1 个百分点, 但这只说明拿着它的现金回报不算低, <Red>不代表它一定会涨</Red>

## 长期年化 10% 是真的, 腰斩也是真的

场景: 你听说 "股票长期年化 10%", 算了一下觉得稳了

朴素做法是把 10% 当成每年都有的利息. 坏在这是几十年的平均数, 中间的路非常颠

先看好消息, 都是含分红的全收益

<Stats items={[
{ value: "约 10.0%", label: "标普 500 年化, 1928 到 2025", source: "纽约大学 Damodaran 数据, 2026-01 更新" }, { value: "9.71%", label: "沪深 300 全收益年化, 2005 到 2025", source: "SBBI 2025 中国版" }, { value: "4.36%", label: "同期中国长期国债年化", source: "SBBI 2025 中国版" }, { value: "2.13%", label: "同期 CPI 通胀", source: "SBBI 2025 中国版" }, ]} />

再看代价. 沪深 300 在 2007-10 到 2008-11 跌了 72.3%, 2015 股灾跌 46.7%, 2021 到 2024 年初又跌了四成多. 跌 72.3% 之后, 要<Gold>涨 261% 才能回本</Gold>

所以 "能不能扛住" 比 "收益多少" 重要得多. 中国市场的历史只有 20 年, 过去的 9.71% 不保证未来也有

## 复利只奖励起得早和费用低的人

场景: 你觉得每月 500 太少, 等工作了有钱再说

朴素想法是本金小就没意义. 坏在复利最值钱的变量是时间, 不是本金

下面是每月月末投 500 元, 投 20 年, 本金合计 12 万的结果. 按固定年化, 月复利, 不计费用和税自己算的, 现实中每年收益忽高忽低, 这里只演示数学

<Chart kind="bar" unit="万元" source="自算: 终值 = 500 × [(1 + r/12)^240 − 1] ÷ (r/12)" caption="同样 12 万本金, 年化差几个点, 20 年后差出一倍" data={[
{ name: "年化 0.8% (像余额宝)", value: 13.0 }, { name: "年化 4%", value: 18.34 }, { name: "年化 7%", value: 26.05 }, { name: "年化 10%", value: 37.97 }, ]} />

记一个口算工具, 72 法则: 翻倍年数 ≈ 72 ÷ 年化收益率. 10% 约 7 年翻倍, 4% 约 18 年. 反过来也成立, 欠一笔 18% 的债, 4 年就翻倍

所以真正该在意的两件事: <Red>早点开始, 费用压低</Red>. 每年多 1% 的管理费, 20 年下来吃掉的是一大截终值
