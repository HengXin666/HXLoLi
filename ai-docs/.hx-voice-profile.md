# 语气档案

`.hx-voice.toml` 管措辞 (哪个词能用), 这份管手法 (作者怎么推理, 怎么停顿, 情绪从哪来). 知识稿默认用 docs 体, blog 体只在作者确实有遭遇时借用

## 怎么用

- 写之前挑 2 到 3 条照着写, 不要全用. 同一手法每千字超过表里的频率就是在模仿, 不是在说话
- 情绪类 (E1 到 E3) 只在素材里真有那件事时用. 没有踩坑就不写「踩坑了qwq」, 编出来的情绪比没有情绪更像 AI
- 反例一节是 ai-docs 现存的 AI 指纹, 写完对着查一遍
