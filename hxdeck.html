Diagram / architecture

架构图: 滚轮缩放 · 拖拽平移

内联 SVG 跟随主题换色; 滚轮只缩放图, 不会把页面滚走.

  • 滚轮 = 缩放, 拖拽 = 平移
  • 不用 iframe: 内联 SVG 才与版面共用字体与圆角
  • 配色全部来自主题变量, 切主题图跟着变

Embed

外挂: drawio / HTML / 图片

drawio 走 img 以保留可编辑性; HTML 走 iframe 以隔离样式.

  • Embed kind="drawio" —— 在线可编辑的矢量图
  • Embed kind="html" —— 任意自包含 HTML
  • Embed kind="image" —— 普通图片, 自动推断
把 .drawio.svg 或导出好的 .html 放进本目录, 用 Embed 引用即可.
