# Agent Note: 字数图拆成"堆叠面积 + 增量柱"两块, 取消双纵轴

Status: implemented

Decision-ID: word-count-chart-zero-baseline

## Code

- `src/components/chart/WordCountChart/index.tsx`

## Problem

历史笔记字数统计图把四条线 (增量, docs/blog, ai-docs, 总量) 画在一张图的两根纵轴上.

左轴是单次增量, 只要区间里有一次删字提交 (实测最小 -47,788) 就会被拉到负数; 右轴是累计, 从 0 起. 两根轴的 0 不在同一高度, 累计曲线看起来是从左轴的负数出发的. 上一轮试过把两根轴分段对齐, 0 是对上了, 但实际渲染里还有重叠: ai-docs 出现之前 docs/blog 与总量两条线完全重合; ai-docs 线在 0 附近又与增量线贴在一起; 增量的尖峰与累计线互相穿插. 提交说明还曾被画成一条 `dataKey="message"` 的字符串曲线挂在右轴上.

## Decision

拆成上下两块共用横轴的图. 上块是 docs/blog 与 ai-docs 的堆叠面积图, 顶边就是总量, 两条线不再重合, ai-docs 的厚度就是它的占比; 纵轴从 0 起, 上界按 `niceCeil` 取 1 / 2 / 2.5 / 5 的整倍数, 均分四段. 下块是每次提交的增量柱, 正值 `#FF61FF`, 负值 `rgb(97, 255, 97)`, 0 线常显; 纵轴正向按 `niceCeil(max)`, 负向最多取正向的一半, 更深的删字由 `allowDataOverflow` 压底. 刷选条放在下块, 上块按同一区间切片. 悬停提示统一给日期、提交说明、总量、两类累计与本次增量.

图头给当前总字数和刷选区间内的净增量. 横轴刻度只显示年月. 颜色沿用原图四色.

## Alternatives considered

- 什么都不做 / 只把左轴下界写成 `Math.min(0, min)`: 一行改动. 否决是因为两根轴的 0 仍对不齐, docs/blog 与总量的重合也还在.
- 保留双纵轴, 让两根轴按相同分段对齐 0 (上一轮做法): 不改图表结构. 否决是因为实际渲染里四条线仍然互相压住, 读不出 ai-docs 的占比.
- 增量改用对称 domain `[-max, max]`: 正负都可见. 否决是因为正向分布远大于负向, 对称轴让大部分柱子挤在上半段.
- 用对数轴压住量级差: 一次看到全部数据. 否决是因为增量有 0 和负值, 对数轴在这些点上断开.

## Consequences

图表高度从 400px 变为上块 200px + 下块 96px + 图头, 首页首屏更短. 两块图不联动悬停 (recharts 的 syncId 会把刷选区间再同步一次, 与上块的切片冲突), 各自给完整提示. 组件的 `rawData` / `initialPercent` 参数不变, 新增可选的 `height`.
