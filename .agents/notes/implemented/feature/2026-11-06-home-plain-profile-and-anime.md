# Agent Note: 首页去掉角色头图, 追番块改成细线列表

Status: implemented

Decision-ID: home-plain-profile-and-anime

## Code

- `src/components/home/HomeAnime.tsx`

## Problem

2026-11-06 用户对首页两处不满, 原话 "特别是角色配图, 以及追番记录. 全部都是垃圾太 ai 味道". 角色配图是左栏个人卡顶上的 main_menu_misaka 横幅 (发光背景 + 头像压在横幅下沿); 追番记录是一个圆角面板, 里面是 6 格大数字统计 + 6 张大封面 + 标签行. 封面在 CDN 慢时是 6 个空白框, 标注表为空时标签行只剩一个孤零零的 "标签" 字. 页面底还铺了一层点阵, 趋势图按钮带渐变底、扫光和模糊展开, 与番剧页第二版删掉的是同一类装饰.

## Decision

个人卡不再放角色配图: 删掉横幅, 头像改为 48px 方形小圆角 + 1px 边, 与名字并排, 下方 1px 分隔. 卡片圆角 16 -> 6, 统计格圆角 10 -> 4, tagline 用等宽字. `.page` 的点阵底纹删除.

追番块 (`HomeAnime`) 放在 `.panel` 面板里 (1px 边, 12px 圆角), 从上到下: 6 格计数 (记录 / 看过 / 在看 / 搁置 / 想看 / 抛弃, 1px 分格, 等宽数字, 记录用主色) -> 最近更新进度的 6 部在看封面 (12:17 封面 + 番名 + "已看 / 总话数 · 评分" 一行等宽小字, 悬停封面描主色边并上浮 2px, 番名变主色) -> 标签行 (前 10 个有计数的标签, 萝莉排第一时用主色描边高亮; 右侧 "全部追番 →"). 标签行始终渲染. 996px 以下计数与封面都改为 3 列.

"展开趋势图" 按钮改为文字按钮 + 下划线, 展开只保留 grid-template-rows 高度过渡与淡入, 去掉光带、模糊、clip-path 与渐变底.

## Alternatives considered

- 什么都不做 / 复用现有方案: 零改动. 否决是因为用户点名这两块不满意, 现有横幅与封面面板就是问题本身.
- 保留横幅只换一张图: 否决, 用户点名不要角色配图, 换图还是同一个结构.
- 追番块改成 1px 分隔的细线列表 (小封面 + 进度条 + 日期, 与 "最近更新" 同构): 首页读起来是一套语汇. 现在的代码没有采用, 追番块仍是计数格 + 封面格 + 标签行.

## Consequences

同目录的 HomePage.tsx (删横幅) 与 page.module.css 一并改动, 按每目录一个代表文件的规则只在 HomeAnime.tsx 放锚点. `static/img/main_menu_misaka-*.webp` 首页不再引用 (文件保留, 没有删). 首屏少一张约 30-60 KB 的图. `.banner` 与 magic 光带相关样式已删; `.animeStats` / `.animeStat` / `.animeCovers` / `.animeCover` 仍在用. page.module.css 是非 AST 资源, 需人工核对. 截图是 1440 亮色, 番剧标注用的是 mock. 本 note 的锚点在 HomeAnime 默认导出的注释里.
