# Agent Note: 首页去掉角色头图, 追番块改成细线列表

Status: implemented

Decision-ID: home-plain-profile-and-anime

## Code

- `src/components/home/HomeAnime.tsx`

## Problem

2026-11-06 用户对首页两处不满, 原话 "特别是角色配图, 以及追番记录. 全部都是垃圾太 ai 味道". 角色配图是左栏个人卡顶上的 main_menu_misaka 横幅 (发光背景 + 头像压在横幅下沿); 追番记录是一个圆角面板, 里面是 6 格大数字统计 + 6 张大封面 + 标签行. 封面在 CDN 慢时是 6 个空白框, 标注表为空时标签行只剩一个孤零零的 "标签" 字. 页面底还铺了一层点阵, 趋势图按钮带渐变底、扫光和模糊展开, 与番剧页第二版删掉的是同一类装饰.

## Decision

个人卡不再放角色配图: 删掉横幅, 头像改为 48px 方形小圆角 + 1px 边, 与名字并排, 下方 1px 分隔. 卡片圆角 16 -> 6, 统计格圆角 10 -> 4, tagline 用等宽字. `.page` 的点阵底纹删除.

追番块与 "最近更新" 同一种写法, 不再套 `.panel`: 一行文字计数 (小字标签 + 等宽数字, 1px 竖线分隔, 记录数用主色) -> 1px 分隔的 6 行列表 (36x51 小封面 / 中文名 + 原名 / 2px 进度条 + 已看/总话数 / 评分 / 最后更新日期, 悬停与 notes 行一致) -> 页脚 (有计数的标签, 纯文字 + 计数, ロリがある 用主色; 右侧 "全部追番 →"). 标签为空时整行不渲染. 996px 以下列表行变成两行 (进度条落到名字下面, 日期隐藏).

"展开趋势图" 按钮改为文字按钮 + 下划线, 展开只保留 grid-template-rows 高度过渡与淡入, 去掉光带、模糊、clip-path 与渐变底.

## Alternatives considered

- 什么都不做 / 复用现有方案: 零改动. 否决是因为用户点名这两块不满意, 现有横幅与封面面板就是问题本身.
- 保留横幅只换一张图: 否决, 用户点名不要角色配图, 换图还是同一个结构.
- 追番块保留封面墙只缩小: 否决, 封面墙是用户点名的那块; 列表与 "最近更新" 同构, 首页读起来是一套语汇.

## Consequences

同目录的 HomePage.tsx (删横幅、追番节去掉面板) 与 page.module.css 一并改动, 按每目录一个代表文件的规则只在 HomeAnime.tsx 放锚点. `static/img/main_menu_misaka-*.webp` 首页不再引用 (文件保留, 没有删). 首屏少一张约 30-60 KB 的图. `.banner`、`.animeCovers`、`.animeCover`、`.animeStat`、magic 光带相关样式已删. page.module.css 是非 AST 资源, 需人工核对. 截图是 1440 亮色, 番剧标注用的是 mock (data/labels 为空时标签行不出现).
