# Agent Note: 区分口播与书面两种媒介的写作手法

Status: implemented

- **引入于**: `f28d9cfd13`
- **引用落点**: 无源码引用 (约束的是 templates/interest-outlook.md 里的写法条款, 无对应代码声明)
- 影响: `templates/interest-outlook.md` 的引入一节 (第二人称与预告目录两条放宽) 与正文一节 (补入四条书面手法 + 说明口播手法为何不收录)

## Problem

前一阶段为「去 AI 味」建判据时, 素材**全部来自技术视频的口播转写**。从中总结了七条手法
(接住困惑再往下讲 / 自问自答推进 / 失败讲成交互 / 用问题引出动作 / 报菜单 / 取舍要说清 /
给读者能带走的东西), 并据此改了两条模板规则 (禁止第二人称、禁止预告目录)。

问题: **视频和文章不是同一种媒介, 手法不能互相搬。**

拿真人**技术博客**复核后 (edsionte / 博客园 luconsole / LittleHann / CSDN —— 来源是作者自己
一篇博客里引用的 12 个链接), 七条里只有**两条**在文章里成立。

## Decision

按媒介划清界限:

| 层面 | 内容 | 收到哪里 |
|---|---|---|
| 通用内容判据 (两条) | 取舍要说清 / 给读者能带走的东西 | 模板正文 |
| 书面文章手法 (四条) | 背景+问题+思路 / 标题用想做什么 / 给两种做法 / 结尾允许态度 | 模板正文 |
| 口播手法 (五条) | 接住困惑 / 自问自答 / 失败讲成交互 / 用问题引动作 / 报菜单 | **只留档在 research-output, 不进模板** |

同时放宽两条被证据推翻的旧规则:

- **「禁止第二人称」** -> 改成看**后面有没有具体场景**。笔吧评测室的开场「你有没有这种经历啊」
  紧接着给了三个具体动作 (打开电商页面 -> 想不出关键词 -> 看着都一样), 读者能对上号, 成立。
  而「相信你也遇到过」没有场景, 只是招呼, 不成立。
- **「禁止预告目录」** -> 同样不是一律禁止。教学向内容常这么开场 (灵茶山艾府「首先我会讲…」),
  它让读者先知道这趟值不值得跟。差在说的是「我要讲什么」还是「你能拿到什么」。

## Alternatives considered

- **把七条全写进模板** — 最强理由: 它们确实是从真人素材里读出来的, 不是凭空编的。
  否决: 复核显示其中五条在书面文章里**不成立**。写进去会把「陪着听众走」的口播习惯硬塞给
  可以自己回看的读者 —— 这不是风格差异, 是媒介错配。
- **一刀切只保留两条通用判据, 文章手法也不写** — 理由: 样本仍偏少 (4 篇), 再收窄更保险。
  否决: 那四条是从 4 篇互相独立的真人文章里**都有**的特征 (背景+思路、给选择、结尾态度、短),
  不是某一篇的习惯; 且它们与现有条款不冲突。
- **先不改, 等样本更多再说** — 理由: 判断建立在 4 篇文章上, 可能不够。否决: 现有的两条规则
  (禁第二人称 / 禁预告目录)**正在主动否定正确写法**, 留着比改错更糟。

## Consequences

- 模板从只讲「形式约束」(禁表格/禁大段/代码块标题) 变成**也讲内容要求**, 这是它此前缺的一层。
- 代价: 模板涨到 293 行。它是 L3 (按需读, 不占 SKILL.md 的 500 行预算), 但意味着写引入时要读更多。
  **暂不拆分** —— 写引入与正文时确实需要读全, 拆开反而要读两个文件。
- 留档位置: `research-output/spoken-style-corpus.md` (七层, 661 行) 记着完整推导与全部原始语料。
  那份文档**不是交付物**, 是取证材料 —— 后续若有人质疑某条判据, 去那里查它从哪来。
