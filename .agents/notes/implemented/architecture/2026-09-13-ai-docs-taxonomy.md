# Agent Note: ai-docs 目录重分类: 从「来源/体裁」维度切到「学科」维度

Status: implemented

- 影响: `ai-docs/` 全库目录结构 (28 篇笔记) + `sidebarsAiDocs.ts` + 跨文章链接

## Problem

ai-docs 的目录树混了三种切分维度, 读者无法通过树导航:

1. **容器层**: `002-知识沉淀/` 把本该是一级的学科 (编程语言/LLM与Agent/浏览器验证) 全压到第二层.
2. **按来源分**: `002-项目学习/` 里 7 篇唯一的共性是「都是我对某个项目的学习」. 来源相同不代表主题相关, 分类名对读者没有导航价值.
3. **按体裁分**: `003-想法探索/` 与学科分类平级.
4. **大类名过长**: `006-浏览器验证与AI逆向/` 是复合长名 —— 把「浏览器信号检测」和「AI 逆向」两个方向硬捏在一起.

对照站点另一棵树 `docs/` (929 篇, 11 个一级, 全是 2~6 字短词, 深度 3~7 层), 它的 L1 全部回答同一个问题:「你想找哪个方向的知识?」

## Decision

**唯一合法的切分维度是「这是什么知识」**; 来源 / 体裁 / 载体 / 时间都不能当大类. 树形规则见 `.agents/skills/hx-docs-organize/references/taxonomy-directory.md`.

最终树 (5 个根, 全部 <=4 字):

```text
ai-docs/
  001-关于/                      单页, 非分类
  001-程序语言/    5 篇   001-现代C++ / 002-Python / 003-Web前端
  002-AI/         18 篇   001-基础 / 002-Agent架构 / 003-Agent-Harness / 004-记忆
                          005-Skill / 006-多智能体 / 007-检索 / 008-AI逆向
  003-工具链/      2 篇   (直接挂文章, 无 L2)
  004-生活/        1 篇   电脑包选购指标
  005-杂谈/        1 篇   短视频=精神鸦片
```

关键取舍 (人类确认过的):

| 决策 | 结论 | 理由 |
|---|---|---|
| 浏览器验证与AI逆向 | 并入 `002-AI/008-AI逆向`, 不独立成根 | 它本就长在 AI 生态里; 长名是病征 |
| 这 4 篇叫什么 | `AI逆向`, **不叫「前置知识」** | 它们是独立的对抗领域, 不是学 AI 的前置; 叫前置会让索引失效 |
| `005-杂谈` | 保留 | 体裁不成大类是通则, 但个人库有个诚实的 catch-all 优于硬塞; 规则原意是防切碎连贯领域 |
| `003-工具链` | 独立成根, 不并入 `002-AI` | 讲「用工具」而非「造 Agent」, 不是一回事 |
| 用词 | `程序语言` | 与 `docs/002-程序语言` 完全同名, 两棵树同一套词 |
| DSH 预设提示词全解 | 归 `003-Agent-Harness`, 不进 `001-基础` | 它是 harness 机制而非通用 LLM 基础 |
| **L2 按机制命名, 不按产品名** | `003-DSH` -> `003-Agent-Harness` | **自我纠错**: 初版按产品建了 `003-DSH`, 违反本规范自己的「载体/工具不能当分类」. 四篇的 tag 里都有 `Harness` —— 词汇表早把它当概念了. DSH 只是 Agent Harness 的一个**实例**; 按机制命名后, 以后写 Claude Code / Codex CLI 也能自然归入 |
| `001-关于` 改名 | **不改** | 实为站点页脚链接, 改了 404; 保留编号占位 |

## Alternatives considered

初版规范写了「同一大类内部深度必须一致」, **被 `docs/` 实测证伪**: 它的深度分布是 L3:78 / L4:278 / L5:344 / L6:206 / L7:20, 需要细分的地方就往下长. 已改为「深度是结果不是目标; 要警惕的是同一主题出现两种深度」.

## Consequences

- `002-知识沉淀/` 与 `002-项目学习/` 两个容器层消失, 所有文章路径变更 -> **URL 全变** (站内无重定向).
- 每篇笔记的 `hxid` 保留不变, 跨文章引用因此可在移动后自动重算.
- 目录名去空格 2 处, 改等号 1 处.
- `ai-docs/deck-embed-test.md` 删除 (临时测试页, 且侵入知识库根).
- 需重跑: `generateAiDocsSidebar.js`, `hx_docs_id.py resolve --write`, 以及第 5 步的标点归一化.
