# 主题与版式规范

## 配色变量

沿用现有侧车的暗色系, 只改 `--accent` 做区分:

```css
:root{
  --bg:#0a0f1e;      /* 页面底色 */
  --panel:#111a30;   /* 卡片/舞台 */
  --line:#223352;    /* 描边 */
  --ink:#e9effc;     /* 主文字 */
  --muted:#92a3c8;   /* 次要文字 */
  --accent:#38d3f2;  /* 强调色, 主题色 */
  --accent2:#a78bfa; /* 次强调 */
}
```

- 正文基准字号 18~22px; 封面标题 56~64px; 页标题 28~32px. 演示页是**远看**的, 不要用 md 正文的字号.
- 一页最多一个强调色; 强调靠**颜色 + 位置**, 不靠加粗堆叠.
- 字体栈写 `"PingFang SC","Noto Sans SC","Microsoft YaHei",system-ui,sans-serif` —— 不引外部字体.

## 版式结构

每页固定骨架:

```html
<section class="slide">
  <div class="shead"><span class="snum">01</span><h2>页标题</h2></div>
  <div class="stage"><!-- 本页内容 --></div>
  <div class="scap">一句话说明这一页要说明什么</div>
</section>
```

- `.snum` 用两位数字, 与 md 里的 `0xNN` 章节号对齐, 便于读者对应.
- `.stage` 是唯一可滚动区域; 内容超出时**拆页**, 不要让它内部滚动 (演示页出现滚动条=失败).
- `.scap` 是"这页在说什么"的一行注脚, 不是重复标题.

## 常用版式

| 版式 | 用在 | 要点 |
|---|---|---|
| 封面 | 第 1 页 | 大标题 + 一行 lead + 3~5 个 chips (关键词); 不要放目录 |
| 要点列表 | 论点罗列 | `ul.points li`, 每条 ≤ 2 行; 关键短语用 `<b>` |
| 表格 | 对照/取舍 | 首列用 muted 色, 行数 ≤ 8 |
| 对照双栏 | 前后/优劣 | 左右各一张卡片, 顶部标签不同色 |
| 代码 | 关键片段 | `<pre>` + 等宽字体, 只放能看懂论点的 5~15 行, 不做语法高亮依赖 |
| 引用 | 原文/原话 | 大号引文 + 出处小字 |
| 收尾 | 最后一页 | 结论 + 下一步/展望; 不要写"谢谢观看" |

## 翻页运行时 (模板已含)

- 状态: `.slide.active` 控制显隐 (`opacity` + `pointer-events`), 不要用 `display:none` 以免动画丢失.
- 绑定: `ArrowLeft/ArrowRight/Space/PageUp/PageDown/Home/End` + 点击左右半屏 + 底部按钮.
- 页码: `当前/总数` 由 JS 按 `.slide` 数量实际计算, 不要手写死数字.
- 禁止自动轮播: 读者要能停下来看.

## 排查

| 症状 | 原因 |
|---|---|
| 页面 404 | .html 不在 md 同目录 (插件按"同目录有 md"才拷贝) |
| 样式错乱 | 引了外部 CDN / 相对路径资源; 或依赖了宿主页面 DOM |
| 翻页失效 | iframe 内未拿到键盘焦点: 保留底部按钮与点击翻页作为兜底 |
| 内容被裁 | 用了 `100vh` 而不是固定 1600x900 画布, iframe 高度不足 |
