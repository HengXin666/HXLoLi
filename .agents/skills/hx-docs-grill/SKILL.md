# hx-docs-grill

把一篇 ai-docs 笔记的方向谈到**双方共识**, 再交给成文环节. 对话负责推进, 答题卡负责留痕.

## 核心模型

把要谈的事建构成一棵**设计树**: 每个决策向下分叉出依赖它的决策.

- **frontier (前沿)** = 所有前置已闭环、现在就能问、不必猜测未听到答案的决策.
- 每一轮**只问当前整个 frontier**: 每题编号 + 必须给出**你的推荐答案**, 然后**停下等人类回答**.
- 依赖本轮某个仍未决问题的下游决策, 属于**下一轮**, 本轮不要问.
- 人类每轮回答会重塑这棵树: 已决决策把 frontier 向外推, 解锁依赖它的新问题. 重新计算 frontier, 再开下一轮.
- **终止条件: frontier 为空** —— 每条分支都走过, 没有留下静默假设. 人类确认达成共识前, 不要动笔写正文.

一次问一个问题的"挤牙膏"式追问是**错误用法**: 它让互不依赖的决策被迫串行, 把一次会谈拖成十轮.

## 事实自取, 决策归人

- **找事实是你的活, 不是人类的活.** frontier 上的问题需要环境事实时 (文件、脚本、仓库、文档、网页), 派 sub-agent 去查, 不要问人类任何你自己能查到的东西.
- **不要阻塞**: 一个还在跑的调研就是一个未闭环的前置条件, 只有它的下游问题需要等; frontier 上其余问题**现在就问**.
- **决策必须交给人类**: 逐个摆出来, 然后等.

## 每轮格式

```markdown
❓ **Q1** - **<问题标题>**: <问题正文, 可多段, 可列多个选项>

➡️ <你的推荐答案 + 一句话理由>

---

❓ **Q2** - **<问题标题>**: <问题正文>

➡️ <你的推荐答案 + 一句话理由>
```

每题之间用 `---` 分隔. 推荐答案必须基于当前上下文、代码事实、已有笔记或工程常识给出, 不能把判断责任原样丢回给人类.

## 追问轴 (笔记场景)

沿这棵树逐层往外推, 不要跳层:

1. **目的与读者** —— 这篇是给谁看的? 看完要能做什么? 为什么值得写 (不写会损失什么)?
2. **边界** —— 哪些内容明确**不**写? 说到哪一层为止?
3. **证据** —— 结论依据哪个来源 (视频段落 / 文章 / commit / 实测)? 有没有反例?
4. **侧重与取舍** —— 同一素材有多种讲法时选哪种, 牺牲什么.
5. **验证** —— 读者怎么判断这篇写对了? 哪些说法需要标注不确定?
6. **收尾** —— 标题、tag、引用来源、要不要配演示页.

事实性问题 (如"这个 commit 到底改了什么") 先自行查证, 不要把查证工作包装成问题丢给人类.

## 答题卡 .hx-mitemite.md

需要人类回答或拍板的内容**一律落盘**到笔记目录下的 `.hx-mitemite.md`, 而不是只留在对话里. 它是逐轮追问的记录, 不是一次性问卷.

- 位置: 该笔记目录下 (与 `index.md` 同级), 每篇目录最多一个.
- 每轮**只新增本轮的 frontier**, 上一轮未答的问题不会再问; 已决问题不再重复落盘.
- 能被代码/文档事实回答的问题**不写入答题卡**让人类重复回答.

### 文件格式

```markdown
## 0x00 a1b2c3d4 begin {
**Q**:
问题内容 (可多行 markdown)
**A**:
答案内容 (可多行 markdown, 待填写时留空)
}

## 0x01 b2c3d4e5 begin {
**Q**:
另一个问题
**A**:

}
```

- 序号 `0x00` ~ `0xFF` (十六进制, 按序递增)
- hash 是问题内容的 MD5 前 8 位 hex, 用于唯一标识与变更检测
- 每个 block 以 `}` 独占一行结束
- **校验用正则**: `^##\s+(0x[0-9A-Fa-f]{2})\s+([0-9a-f]{8})\s+begin\s+\{$`

### 写入 (在笔记目录下运行)

```bash
uv run .agents/skills/hx-docs-grill/scripts/hx_mitemite_add.py "0x00" "问题内容"
echo "多行问题" | uv run .agents/skills/hx-docs-grill/scripts/hx_mitemite_add.py "0x01"
```

同一序号再次调用会更新问题并清空旧答案. 也可以直接按上述格式手写文件 —— 脚本只是保证格式一致的手段.

### 读取与回收

```bash
# 查看所有问题状态 (待答/已答), 无参数即列出
uv run .agents/skills/hx-docs-grill/scripts/hx_mitemite_res.py
```

人类回答后, 用 Read 读取该文件、解析各 block 的 `**A**:`. 回收顺序固定:

1. 先**复述更新后的结论或约束**, 让人类确认没有会错意;
2. 再据此重算 frontier, 决定是否需要下一轮;
3. 关键问题全部闭环后, 把答案整合进正文, 停止追问.

## 反幻觉与责任

- 不要臆造人类没说过的结论; 答案为空就是待答, 不能替人类填.
- 人类的描述也可能不准确. 先客观审视, 有疑问就要讨论; 但**不要反过来把人类带偏**. 人类调研后有理有据地坚持己见时, 听人类的.
- 责任永远在人类身上, 你只是辅助: 不允许"自作主张"地替某个决策拍板.
