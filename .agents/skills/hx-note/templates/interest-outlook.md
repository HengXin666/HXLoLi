# 模板: 兴趣&展望 (默认)

读者是**带着好奇**来的. 任务: 读完想去试一试

这份只留槽位与硬判据. 每条判据的来由与反例在 `shared/voice/impl/outlook-rationale.md`, 盲审判 FAIL 时再读

## 写作顺序 (不许倒过来)

1. 先出分镜 `source/storyboard.md` (格式见 `assets/storyboard-template.md`): 每个 `## 0xNN` 一行, 写清主视觉与它要证明的一句话. 分镜给人看过再写字
2. 读 `shared/voice/impl/exemplars.md`, 照样本语气只写引入段
3. 按分镜逐段写: 先放主视觉, 再写接住它的那一两句话. 事实只从 `.hx-info.md` 取

## 槽位表

| 槽位 | 上限 | 必填 | 渲染成什么 |
|---|---|---|---|
| 引入 | 50 字 | 是 | `# 标题` 下面的第一段, 不带小标题 |
| 正文段 | 3 到 6 个 | 是 | `## 0xNN <名词短语标题>`, 标题 4 到 17 字 |
| 主视觉 | 每段至少 1 个 | 是 | 图 / 带分组名的代码块 / 不超过 5 行的表格 |
| 连续纯文字 | 每段每处不超过 4 行 | 是 | 超了就拆段或换成视觉 |
| 全文纯文字行 | 不超过 30 行 | 是 | 不含代码块、表格、图、标题、frontmatter |
| 可复用物 | 至少 1 件 | 是 | 带分组名的代码块或同目录侧车, 且被一句话引进论点 |
| 展望 | 50 字 | 选填 | 最后一段的收尾句, 必须是能被反驳的判断; 写不出就不写 |

## 硬判据 (lint / doctor 会查)

- 引入写的那件事, 在决定写这篇之前就发生过. 没有真实遭遇就写真实动机, **不编**
- 每个 `## 0xNN` 段都有主视觉 (`hx_voice.py lint` 的 `section-visual` 规则, E 级)
- 每段纯文字行数与视觉数之比不超过 4 (`text-ratio` 规则)
- 表格最多 5 行数据行; 更大的表用 `lint --allow-table` 并说明理由
- 每张图后面紧跟一句话把它接进论点; 不被引用的图删掉
- 不写"参考来源"章节: 站点会从正文链接自动生成
- 论断按来源等级写: T1 直接陈述, T2 写"据 某某", T3 只当线索 (等级定义见 `steps/2-collect/impl/research.md`)

## 这个模板拒绝什么

- API / 配置速查: 那种内容适合大表格和穷举, 直接写进 `docs/`
- 纯故障复盘: 用 `templates/problem-solution.md`
- 没有真实素材的主题: 所有事实都必须能在 `.hx-info.md` 里找到依据
