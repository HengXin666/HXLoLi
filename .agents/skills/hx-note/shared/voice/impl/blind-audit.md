# 盲审协议

## 为什么必须"盲"

自己审自己一定过。模型对自己刚写的文本有 self-preference bias: 它已经知道每句话
"想表达什么", 于是会把"我懂"误判成"写清楚了"。同一个上下文里追加一句"再审一遍"
基本等于没审。

所以盲审的定义是: **换一个不知道来龙去脉的 agent, 只给产物和判据。**

## 三条污染控制铁律

1. **不透露身份**: 不能说"这是 AI 写的"、"这是我写的"、"你在被测"。一旦说了,
   sub-agent 会去迎合你的期待, 报告失去信息量。
2. **不透露过程**: 不给素材链接、不给 `.hx-info.md` (AI 味盲审时)、不给模板名、
   不给流程阶段、不给上一轮审计结论。
3. **不透露答案**: 不说"我觉得第 3 段有问题"。你怀疑的地方恰恰是最需要独立验证的。

判定规则: **如果 sub-agent 只在看到泄漏信息时才能得出正确结论, 这次盲审作废。**

## 两类审, 顺序不能换

| 审 | 时机 | 给什么 | 拦什么 | prompt |
|---|---|---|---|---|
| AI 味盲审 | 人类评审阶段, 与人类意见并行 | 只给 `index.md` | 不说人话 | `../../../assets/voice-audit-prompt.md` |
| 保真盲审 | 定稿前最后一关 | `.hx-info.md` + `index.md` | 重点偏离事实源 | `../../../assets/fidelity-audit-prompt.md` |

顺序固定为"先味道、后保真": 改文风会动句子, 动句子就可能带偏事实, 所以保真必须在最后。
反过来做等于白做一遍。

## 两条硬约束 (实测有据, 不要省)

### 一、评审者必须与生成者**异源**

self-preference 不是猜测, 是实证结论: 模型识别自己输出与偏好自己输出是线性相关的
(Panickssery 等, *LLM Evaluators Recognize and Favor Their Own Generations*, 2024,
<https://arxiv.org/abs/2404.13076>)。同一个模型家族的自评会系统性偏高。

**做法**: 换模型、换 agent 会话、或至少换一个与写作完全无关的上下文。不要在同一轮
对话里"写完再审"。

### 二、成对比较必须**顺序对调**再跑一次

当盲审要让评审者在两个候选之间选(例如两个引入段), 存在位置偏置: 排在前的被选中的概率
显著更高 (<https://arxiv.org/abs/2406.07791>)。

**做法**: (A, B) 与 (B, A) 各跑一次, 两次结论一致才算数; 不一致就说明这一对没有显著差异,
不要凭单次结论下判断。

### 三、不要指望模型自我纠错

无外部反馈的自我修正会**掉分** (<https://arxiv.org/abs/2310.01798>)。所以"让它自己再看看"
不能替代盲审。这条与第一节是同一件事的两面。

## 静态检测与盲审的分工

```
hx_voice.py lint   ->  能被正则抓到的 (破折号/套话/句式/排版密度)
sub-agent 盲审     ->  抓不到的 (意义膨胀/空洞/逻辑跳跃/读起来像谁)
```

**先跑 lint 再派盲审**。理由: lint 能抓的东西让盲审去抓是浪费一次调用, 而且满屏
低级问题会淹没盲审真正有价值的发现。lint 干净了再问"读起来像人吗"。

lint 通过 ≠ 可以交付。它只证明没有已知指纹, 不证明文章好。

## 每次盲审后必须做的一件事

把盲审新发现的表达写回语料库, 否则这次经验下次就不存在了:

```bash
# 坏表达 (给 pattern 的话, 下次 lint 会直接拦住)
uv run .agents/skills/hx-note/scripts/hx_voice.py learn \
  --bad "更反直觉的是" --why "硬造惊讶感的过渡句" --pattern "更(?:反直觉|有意思)的是"

# 好表达 (必须是作者真写过的原句, source 必填)
uv run .agents/skills/hx-note/scripts/hx_voice.py learn \
  --good "感觉有意思就再看一次就完事了~" --why "结尾戛然而止" --source "blog/2026/05/07/01_最近的项目.md"
```

语料库在 `ai-docs/.hx-voice.toml`, 点开头文件不会被站点收录。

## 什么时候可以跳过盲审

只有一种情况: 这次改动没有动过任何句子 (例如只改了图片路径)。其余一律不跳。
跳过时必须在回复里写明原因。
