# AI 味盲审 prompt 模板

派 sub-agent 时**逐字使用**下面的内容, 只替换 `<...>` 占位。

**替换前先检查三件事** (违反任何一条, 这次盲审结果作废):

1. 不要说这篇文章是 AI 写的、是你写的、或者正在被测。
2. 不要给素材来源、`.hx-info.md`、模板名、流程阶段、你自己的怀疑点。
3. 不要给期望结论 (例如"我觉得第 3 段有问题, 你看看")。

---

```text
你是一位中文技术编辑, 负责判断投稿的文字是人写的还是机器生成的。

请阅读 <文章绝对路径>, 然后完成三件事:

一、给出判断
这篇文章更像人写的, 还是更像大模型生成的? 给一个 0-100 的"机器味分数"
(0 = 完全像人, 100 = 完全像机器), 并用一句话说明你的主要依据。

二、逐条列证据
把你认为像机器写的地方全部列出来, 每条包含:
- 行号
- 原文 (短引, 不超过 30 字)
- 为什么像机器 (具体到句式或用词, 不要写"读起来生硬"这种空话)
- 你会怎么改 (给出可直接替换的中文)

如果找不到, 就写"没有找到", 不要为了凑数硬找。

三、找出最像人写的地方
列出 2-3 处你认为最有"人味"的原文, 并说明它们为什么可信。
这一项不许空着 —— 如果全篇都找不出一处人味, 直接说明这件事本身。

参考判据 (不完整, 发现新的请补充):
- 破折号、"不是X而是Y"、"更反直觉的是"、"的本质"、三项排比
- 意义膨胀 (把普通事说成关键转折)
- 每个列表项都是 `- **粗体标题**:`
- 空洞收尾 (未来可期 / 前景光明 / 个人判断式收束)
- 含糊权威 ("专家认为""业界普遍")
- 通篇段落长度一致、加粗密度均匀

输出用 markdown, 三节分开写, 不要额外寒暄。
```

---

## 回收

把 sub-agent 的原文存到 `<笔记目录或暂存目录>/review/voice-audit.md`, 然后:

1. 逐条落实第二节的改法, 或写明为什么不改。
2. 第二节里**每一条新发现的句式**都要进语料库:

   ```bash
   uv run .agents/skills/hx-note/scripts/hx_voice.py learn \
     --bad "<原文>" --why "<为什么坏>" --pattern "<可选正则>" --source "<文件>"
   ```

   给了 `--pattern` 的下一次就会被 `lint` 自动拦住 —— 这是让盲审经验不白丢的唯一办法。

3. 第三节里被认可的原句同样要进语料库 (`--good`), 出处写清楚。
