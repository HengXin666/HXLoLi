# 探头立绘出图规格卡 (catgirl-spec)

实测时间: 2026-11-03 21:5x CST. 样本: HXLoLi/static/img/catgirl/pair1..13-{left,right}.png 共 26 张 (经 fs 隧道原样下载, 未改动).
工具: python3 + PIL + numpy + scipy, 脚本见文末 "核对脚本", 全部数字由脚本算出, 无目测.
命名约定沿用仓库: left 图 = 放正文左侧的槽, 身体贴右、竖直裁切线在右 (x=W); right 图 = 放正文右侧的槽, 身体贴左、裁切线在左 (x=0).
"实像素" = alpha > 127.

## 0. 量的定义 (机械可复算)

| 代号 | 定义 |
|---|---|
| AR | 画布 W / H |
| TOP | 头顶留白: 第一行 "实像素占该行宽度 >= 0.5%" 的 y / H (0.5% 阈值滤掉单根飞发) |
| FIGH | 人物占高 = 1 - TOP (人物底边一律贴画布底) |
| FADE_IMG | 图内淡出起点: 自上而下最后一行 "该行 alpha 最大值 >= 250" 的下一行 / H |
| FADE_CSS | 页面淡出起点: src/components/BlogWithCats/index.tsx NEKO_PAIRS[*].fade (CSS mask 从该比例线性淡到 100% 全透明) |
| BOTCOV | 最底一行实像素占宽 (人物被画布底边截断的宽度) |
| OCC | 最大横向占宽: (全图实像素最右列 - 最左列 + 1) / W |
| CROP_X | 竖直裁切线锚点: left 图 = (实像素最右列 + 1) / W, right 图 = 实像素最左列 / W |
| CROP_COV | 裁切线覆盖: 内侧那一列 (left 图 x=W-1 / right 图 x=0) 实像素行数 / H |
| CX | 实像素水平重心 / W |
| FEATHER | alpha 平均羽化宽度 (px): 半透明像素数 (12 < a < 243) / 实像素轮廓像素数; 只统计 FADE_IMG 以上、且排除内侧 3 列 (裁切线是硬边不算羽化) |

推论 (给归一化与生图共用):
- 画布 = 5:12 竖图; 人物紧贴底边, 占下方 55% 高, 上方 45% 全透明 (入场/上探动画的行程).
- 人物身体一侧被竖直线切开, 切线就是画布内侧边; 切线覆盖约画布高的 45%-50%, 即人物 55% 高里的 82%-90% 都贴着切线.
- 底部淡出不在图里做, 在 NEKO_PAIRS.fade 里逐图给; 归一化交付时要同时给出该图建议 fade 值 (0.84-0.94, 避开手臂).
- 羽化: 抠图后 alpha 只向内收 (gaussian sigma ~1.1px 再与原 alpha 取 min), 内侧 2 列保持硬边.

## 5. 核对脚本 (python3, 只读, 对任意一张图输出全部量并按本卡判定)

```python
# 用法: python3 spec_check.py <png> <left|right>
import sys, numpy as np
from PIL import Image
from scipy import ndimage
p, side = sys.argv[1], sys.argv[2]
a = np.asarray(Image.open(p).convert('RGBA'))[:, :, 3].astype(int)
H, W = a.shape; solid = a > 127
cov = solid.sum(1) / W
top = np.where(cov >= 0.005)[0][0] / H
ys = np.where(solid.any(1))[0]; xs = np.where(solid.any(0))[0]
fade_img = (np.where(a.max(1) >= 250)[0][-1] + 1) / H
occ = (xs[-1] - xs[0] + 1) / W
crop_x = (xs[-1] + 1) / W if side == 'left' else xs[0] / W
inner = a[:, -1] if side == 'left' else a[:, 0]
crop_cov = (inner > 127).sum() / H
cx = np.nonzero(solid)[1].mean() / W
zone = np.zeros_like(solid); zone[:int(fade_img * H) - 2] = True
if side == 'left': zone[:, -3:] = False
else: zone[:, :3] = False
edge = solid & ~ndimage.binary_erosion(solid) & zone
feather = (((a > 12) & (a < 243)) & zone).sum() / max(edge.sum(), 1)
m = dict(AR=W / H, TOP=top, FIGH=1 - top, BOTTOM=ys[-1] >= H - 2, FADE_IMG=fade_img,
         OCC=occ, CROP_X=crop_x, CROP_COV=crop_cov, CX=cx, FEATHER=feather, W=W)
L = side == 'left'
rules = dict(AR=0.4160 <= m['AR'] <= 0.4175, TOP=0.445 <= top <= 0.465,
             BOTTOM=bool(m['BOTTOM']), FADE_IMG=fade_img >= 0.998,
             OCC=(0.51 <= occ <= 0.86) if L else (0.54 <= occ <= 0.97),
             CROP_X=(crop_x == 1.0) if L else (crop_x == 0.0),
             CROP_COV=crop_cov >= 0.25,
             CX=(0.68 <= cx <= 0.80) if L else (0.21 <= cx <= 0.42),
             FEATHER=1.30 <= feather <= 2.30, W=W >= 600,
             CORNERS=all(a[y, x] == 0 for y in (0, H - 1) for x in (0, W - 1)) or True)
for k, v in m.items(): print(f'{k:9s} {v}')
bad = [k for k, ok in rules.items() if not ok]
print('PASS' if not bad else 'FAIL ' + ','.join(bad))
```

自检结果 (2026-11-03, 本脚本跑 26 张 + 样例): 25/26 PASS; 唯一 FAIL 是 pair13-right (BOTTOM, FADE_IMG, CROP_COV), 与第 2 节离群记录一致; sample-right.png PASS.

注: CORNERS 规则对贴底贴边的图天然不成立 (下内角是实像素), 所以只作提示不判失败; 真正的硬要求是 "上方 45% 全透明" 已由 TOP 覆盖.
