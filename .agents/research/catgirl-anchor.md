# 立绘横向落位逐对检查 (2026-11-03 01:15 CST)

方法: 读 static/img/catgirl/pairN-{left,right}.png 的 alpha (>0.5 算实), 量
- cx: 不透明像素水平重心 / 宽 (左槽要 >0.5 = 身体贴右, 右槽要 <0.5 = 身体贴左)
- 裁切线: 内侧那一列 (left 图最右列 / right 图最左列) 实像素占图高比例 (>0 = 身体真的贴到内侧边被切)
- 内侧空隙: 角色各行最靠内侧的实像素到内侧边的距离 / 宽, 取中位数
- anchor: 由以上判定的落位; 要求 left 图 right, right 图 left

## 右侧割裂的真实原因 (推断, 未在浏览器验证)
图是对称的 (见上表), 所以不是构图问题. 两侧唯一的不对称在定位: 立绘 position:fixed, 用 `50% ± 正文宽/2` 推算墙沿, 而 --neko-w 用 100vw (含滚动条);
正文实际位置一旦和推算差几像素 (滚动条、外层容器偏移), 一侧的硬裁切线就露在墙外或和墙隔一条缝. 修法: useWallEdges 量真实墙沿 + 内侧水平淡出兜底.
