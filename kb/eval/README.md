## 文件
- questions.json: 30 题, 含 gold 与 keypoints (出题者只读 kb/raw)
- answers/<主题>-{kb,B,old}.json: 三组答卷 (kb 组只能用 scripts/kb find/use 与 kb/cards, 不含 raw)
- grade/<主题>-blind-input.json: 判分者看到的匿名输入; grade/<主题>-result-blind.json: 判分原表 (X/Y/Z); grade/key.json: 解盲
- compare.md: 逐题对照 (已解盲)
