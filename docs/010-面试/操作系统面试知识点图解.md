## 二、进程 vs 线程 vs 协程

```mermaid
graph TB
    subgraph 进程 Process
        P1[独立地址空间]
        P2[资源分配的基本单位]

        P4[上下文切换开销大]
        P5[一个进程崩溃不影响其他进程]
    end

    subgraph 线程 Thread
        T1[共享进程地址空间]
        T2[CPU调度的基本单位]

        T4[上下文切换开销较小]

    end

    subgraph 协程 Coroutine

        C5["Go goroutine / Python asyncio"]
    end
```

### 高频对比表

| 对比项 | 进程 | 线程 | 协程 |
|--------|------|------|------|
| 地址空间 | 独立 | 共享进程空间 | 共享线程空间 |
| 切换开销 | 大（涉及TLB刷新） | 中（共享页表） | 极小（用户态切换） |
| 通信方式 | 管道/消息队列/共享内存/信号量 | 共享变量 + 同步原语 | channel/yield |
| 调度方 | 操作系统内核 | 操作系统内核 | 用户程序 |
| 并发安全 | 天然隔离 | 需要锁 | 单线程内无竞争 |

## 五、进程同步与互斥

```mermaid
mindmap
  root((同步与互斥))
    互斥锁 Mutex
      同一时刻只有一个线程能持有
      未获取锁的线程阻塞等待
    自旋锁 Spinlock
      忙等待 不让出CPU
      适合锁持有时间极短的场景
    读写锁 RWLock
      读读并发
      读写互斥 写写互斥
    信号量 Semaphore
      计数器控制并发数
      P操作-1 V操作+1
      互斥锁是信号量=1的特例
    条件变量 Condition
      配合互斥锁使用
      wait释放锁并等待
      signal唤醒一个等待线程
    管程 Monitor
      封装共享数据+操作+同步
      Java synchronized原理
```

### 经典同步问题

| 问题 | 核心思路 |
|------|----------|
| 生产者-消费者 | 互斥锁 + 空/满信号量；有界缓冲区 |
| 读者-写者 | 读写锁；读者优先 or 写者优先 or 公平 |
| 哲学家就餐 | 限制同时拿筷子数 / 奇偶编号 / 资源分级 |

## 九、用户态与内核态

```mermaid
sequenceDiagram
    participant U as 用户态进程
    participant K as 内核态

    Note over U: 运行用户代码
    U->>K: 系统调用 (如 read/write)<br/>触发软中断 int 0x80 / syscall
    Note over K: 保存用户态上下文<br/>切换到内核栈
    K->>K: 执行内核代码
    K->>U: 返回结果<br/>恢复用户态上下文
    Note over U: 继续运行用户代码
```

### 用户态→内核态的三种方式

| 方式 | 说明 | 示例 |
|------|------|------|
| 系统调用 | 用户主动请求内核服务 | read/write/fork/exec |
| 异常 | 执行指令时发生错误 | 缺页异常、除零异常 |
| 外部中断 | 外设发出的信号 | 键盘输入、网卡收包、时钟中断 |

```mermaid
graph TD
    A[Linux IO模型] --> B[阻塞IO<br/>Blocking IO]
    A --> C[非阻塞IO<br/>Non-blocking IO]
    A --> D[IO多路复用<br/>select/poll/epoll]

    D --> D1[一个线程监控多个fd<br/>就绪后再read]

    F --> F1[发起后立即返回<br/>内核完成一切后通知]

```

### select / poll / epoll 对比

| 对比项 | select | poll | epoll |
|--------|--------|------|-------|
| 数据结构 | fd_set位图 | pollfd数组 | 红黑树 + 就绪链表 |
| fd上限 | 1024 (FD_SETSIZE) | 无限制 | 无限制 |
| 触发方式 | 水平触发 LT | 水平触发 LT | LT + 边缘触发 ET |
| 检测方式 | 遍历 O(n) | 遍历 O(n) | 回调 O(1) |
| fd拷贝 | 每次调用拷贝到内核 | 每次调用拷贝到内核 | 注册一次即可(epoll_ctl) |
| 适用场景 | 连接数少 | 连接数少 | **高并发首选(万级连接)** |

### epoll 工作流程

```mermaid
sequenceDiagram
    participant App as 应用程序
    participant EP as epoll实例
    participant Kernel as 内核

    App->>EP: epoll_create() 创建实例
    App->>EP: epoll_ctl(ADD, fd) 注册fd
    Note over EP: 将fd加入红黑树<br/>注册回调函数

    App->>EP: epoll_wait() 阻塞等待
    Kernel-->>EP: fd就绪事件触发<br/>回调函数将fd加入就绪链表
    EP->>App: 返回就绪fd列表
    App->>App: 处理就绪的fd
```

## 十二、高频面试题速查

| 问题 | 答案要点 |
|------|----------|
| 进程和线程的区别？ | 进程是资源分配单位，线程是CPU调度单位；线程共享地址空间 |
| 什么是上下文切换？ | 保存当前进程/线程的寄存器、PC、栈指针等，恢复另一个的状态 |
| 什么是虚拟内存？ | 每个进程有独立虚拟地址空间，通过页表映射到物理内存，按需加载 |
| 什么是缺页中断？ | 访问的页面不在物理内存中，触发中断从磁盘加载 |
| 什么是内存抖动/颠簸？ | 频繁缺页，刚换出的页马上又要换入，系统性能急剧下降 |
| fork()的原理？ | 创建子进程，写时复制(COW)共享父进程内存，写入时才真正复制 |
| 孤儿进程vs僵尸进程？ | 孤儿：父进程先死，由init收养；僵尸：子进程先死，父未wait回收PCB |
| 什么是内核态和用户态？ | 内核态可执行特权指令访问所有资源；用户态受限，需通过系统调用进入内核态 |
| 什么是DMA？ | Direct Memory Access，外设直接与内存交换数据，不占用CPU |
| Linux常用IPC方式？ | 管道、命名管道、消息队列、共享内存(最快)、信号量、Socket |
