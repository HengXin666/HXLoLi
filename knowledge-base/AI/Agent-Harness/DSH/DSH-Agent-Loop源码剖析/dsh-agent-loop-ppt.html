S1

输入 → 循环体 → 输出

一条主线看完整个 Agent 循环: 用户提问进入日志, 每步 pre-step 注入上下文后调模型; 需要工具就执行并把结果回灌, 继续循环; 判定结束才输出最终回复.

S2

关键机制 · 三件事

  • 输入是事件, 不是消息 — 用户提问/模型回复/工具结果全部追加进 Session 日志; 模型读到的是日志派生的 surface. 日志与投影分离, 压缩才安全.
  • 注入点唯一 — 上下文只在每个 step 开始前的 pre-step 拼装 (systemPrompt.assemble); 运行时快照作为一条普通消息落进 surface, 可读可压缩.
  • 压缩在循环边界 — pre-step 估算 token ≥ 0.8×窗口即触发; 溢出报错兜底重试; 也可 /compact 手动触发. 历史被摘要替换, 日志保留可追溯.

记住这三件事, 主线图里的每个框就都说得通了.

一句话带走
